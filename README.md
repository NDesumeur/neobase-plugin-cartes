# Cartes

Collectionne les 523 créatures de NeoBase sous forme de cartes.

- **Un paquet gratuit par jour**, ouvert carte par carte avec une animation.
- **Six raretés** aux probabilités différentes, affichées dans la boutique ; une carte épique ou mieux est garantie au plus tard tous les 20 paquets.
- **Doublons** : revends-les pour de la monnaie virtuelle (40 % de la valeur de leur rareté).
- **Boutique** : achète d'autres paquets avec cette monnaie.
- **Collection** et **inventaire** avec filtres, et **historique** de toutes les ouvertures.
- **Sauvegarde sûre** : chaque achat, vente ou ouverture est une transaction enregistrée d'un seul bloc, sans duplication possible de cartes ni de monnaie.

## Installer

Dans NeoBase : **NeoStore → À découvrir → Cartes → Installer**.
